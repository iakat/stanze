The file is unchanged apart from the root element: the editor layer name is
dropped and an intrinsic width and height are written, so a canvas can draw it
without a layout pass. The drawing is a Hatsune Miku wig with the face cut out;
the mask places the cut-out on the face and lets the camera show through it.

Hatsune Miku is a character of Crypton Future Media, Inc. This file is a fan
drawing of the character, released by its author under CC0.
