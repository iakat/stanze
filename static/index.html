Peer to peer audio and video, sealed in the browser. Nothing is stored and nothing is recorded.

Any name works. The suggested id is random and hard to guess; a name you type is easy to guess.

Every room is sealed end to end in the browser: your name, the chat and the media stay there, with X25519 + ML-KEM-768 and AES-256-GCM. The server only forwards sealed blobs. Compare the emoji code with the other people to rule out a swapped key.

Choose the camera and the microphone before the join. The names appear after the browser has asked once, and the choice is remembered.
